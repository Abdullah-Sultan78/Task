

## About project
Here is a  simple Laravel CRUD operation. I use a Category and a Product table. I add products using category as the foreign key.
In this project, you can add products  without seeder or with a seeder as you wish.

## Using Seeder
Using seeder you can add product. Firstly create a Category. Then, Just change the category_id  in the ProductSeeder file. Then,
seeder run command: php artisan db:seed --class=ProductSeeder
